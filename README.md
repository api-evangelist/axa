# AXA (axa)

AXA is a French multinational insurance firm and one of the world's largest providers of life, health, property & casualty, and asset management services. AXA does not publish a single global developer portal; integration happens through country broker portals, AXA Partners embedded-insurance channels, AXA XL specialty workflows, and ACORD / EDI standards.
